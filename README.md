# V. Kamesh — Executive Developer Portfolio

A bespoke, high-performance, and elegant developer portfolio built for **V. Kamesh** (Java Developer & MCA Graduate).

Designed with architectural rigor and editorial luxury aesthetics—deliberately avoiding AI clichés (no neon purple bubbles, no overused Inter font, no generic templates).

---

## 🏛️ Design & Architectural System

- **Design Philosophy**: High-End Architectural Craftsmanship & Dynamic Tonal Layering.
- **Theme Modes & Palettes**:
  - **Obsidian Noir (Dark Mode - Default)**: Deep obsidian slate (`#07080B`, `#0B0D12`, `#10131A`).
  - **Executive Ivory (Light Mode)**: Crisp paper-white architectural layout (`#F8FAFC`, `#FFFFFF`) with dark slate typography (`#0F172A`).
  - **Dynamic Accent Themes**: Champagne Gold (`#DFC28D`), Java Emerald (`#10B981`), and Electric Cyan (`#06B6D4`).
- **Typography**:
  - **Display / Headlines**: `Cabinet Grotesk` & `Outfit` (Sculptural, authoritative, modern European geometric display).
  - **Body Copy**: `Plus Jakarta Sans` (Crisp, contemporary readability).
  - **Technical Telemetry / Code**: `JetBrains Mono` (Engineering rigor & diagnostic authenticity).
- **Structure**: Mathematical grid lines with subtle architectural crosshair (`+`) markers.

---

## ⚡ Technical Stack

- **Framework**: React 18 + Vite 5 (Sub-second HMR & vendor chunk splitting)
- **Styling**: Tailwind CSS + Custom Architectural Grid & Glass Layering
- **Icons**: Lucide Icons + Precision Custom SVGs
- **Telemetry**: Live Indian Standard Time (IST) sync, Interactive CLI diagnostic terminal, Interactive RBAC Clearance Simulator (Aegis Protocol), 5-Tier Blockchain Supply Chain Stepper, and Offline Ledger Budget Simulator.
- **Deployment**: Vercel ready with HTTP security headers and immutable caching rules (`vercel.json`).

## 🚀 Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build optimized production distribution
npm run build

# 4. Preview the production build
npm run preview
```

## 🌐 One-Click Deployment to Vercel

```bash
# Direct deploy via Vercel CLI
vercel

# Or push to GitHub and connect repository in Vercel Dashboard
git push -u origin main
```
